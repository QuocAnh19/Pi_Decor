# Mô Hình Kiến Trúc C4 Hệ Thống Pi Decor (C4.md)

Tài liệu mô tả kiến trúc phần mềm Pi Decor theo mô hình C4 (Context, Containers, Components) trực quan hóa bằng Mermaid.

---

## 1. C4 Level 1: Ngữ Cảnh Hệ Thống (System Context)

Mô tả sự tương tác giữa người dùng, hệ thống Pi Decor và các dịch vụ bên thứ ba.

```mermaid
flowchart TD
    subgraph Users ["Người dùng hệ thống"]
        Guest["Khách tham quan / Cặp đôi<br/>(Duyệt mẫu, thiết kế Studio, gửi lead)"]
        Admin["Quản trị viên / Chủ tiệc (Owner)<br/>(Quản lý CRM, báo giá, kiểm duyệt)"]
    end

    subgraph PiDecorSystem ["Hệ thống Pi Decor"]
        PiDecor["Website & Nền tảng Pi Decor<br/>(Monorepo: Web React SPA + API Express)"]
    end

    subgraph ExternalServices ["Dịch vụ & Nền tảng bên thứ ba"]
        Cloudinary["Cloudinary CDN<br/>(Lưu trữ & tối ưu hóa hình ảnh/album)"]
        Sentry["Sentry IO<br/>(Giám sát lỗi & hiệu năng ứng dụng)"]
        OSM["OpenStreetMap Tile Server<br/>(Bản đồ hiển thị địa điểm sự kiện)"]
        PostgresService["PostgreSQL Database Server<br/>(Neon Cloud / Local DB)"]
    end

    Guest -->|"Truy cập web, gửi yêu cầu tư vấn, trải nghiệm Studio"| PiDecor
    Admin -->|"Đăng nhập quản trị, quản lý lead, tạo báo giá"| PiDecor
    PiDecor -->|"Tải lên & phân phối ảnh sự kiện"| Cloudinary
    PiDecor -->|"Báo cáo lỗi ngoại lệ thời gian thực"| Sentry
    PiDecor -->|"Tải các mảnh bản đồ (tiles) Leaflet"| OSM
    PiDecor -->|"Đọc & ghi dữ liệu quan hệ an toàn"| PostgresService
```

## 2. C4 Level 2: Sơ Đồ Container (Containers Diagram)

Mô tả các container độc lập cấu thành giải pháp phần mềm Pi Decor và giao thức truyền thông giữa chúng.

```mermaid
flowchart TD
    subgraph Clients ["Trình duyệt người dùng"]
        Browser["Trình duyệt Web (Desktop / Mobile)<br/>(Chrome, Safari, Firefox, Edge)"]
    end

    subgraph PiDecorPlatform ["Nền tảng ứng dụng Pi Decor"]
        WebSPA["Web Single Page App (apps/web)<br/>React 18, Vite, TypeScript, SCSS Modules<br/>Cổng: 5173 / Static Hosting"]
        APIExpress["RESTful API Server (apps/api)<br/>Express 5 ESM, Node.js 20, Pino Logger<br/>Cổng: 5001"]
        SharedPkg["Gói dùng chung (@pidecor/shared)<br/>Zod Schemas, DTO TypeScript, SĐT Regex"]
    end

    subgraph DataAndStorage ["Lưu trữ & Dữ liệu"]
        Postgres["Cơ sở dữ liệu PostgreSQL<br/>Quan hệ toàn vẹn, JSONB, Trigram Index"]
        CloudinaryStore["Dịch vụ Media Cloudinary<br/>Lưu trữ ảnh bìa, album Lookbook"]
    end

    Browser -->|"HTTPS / Tải HTML, CSS, JS Bundle"| WebSPA
    Browser -->|"JSON qua HTTPS / REST API /auth, /leads, ..."| APIExpress
    WebSPA -.->|"Chia sẻ Schemas & DTO compile-time"| SharedPkg
    APIExpress -.->|"Xác thực Schemas & Types run-time"| SharedPkg
    APIExpress -->|"pg Pool (SSL, Auto Retry, Retries)"| Postgres
    APIExpress -->|"Upload ảnh kiểm duyệt / Xóa ảnh mồ côi"| CloudinaryStore
```

## 3. C4 Level 3: Thành Phần API Backend (apps/api Components)

Mô tả cấu trúc module hóa phân tầng (Layered Modular Architecture) của dịch vụ `apps/api`.

```mermaid
flowchart TD
    subgraph Ingress ["Tầng tiếp nhận yêu cầu (Ingress)"]
        HTTPReq["HTTP Request"] --> Middlewares
        subgraph Middlewares ["Middlewares dùng chung"]
            MW_Helmet["Helmet Security Headers"]
            MW_Cors["CORS Allowlist"]
            MW_Rate["Rate Limiter (General / Strict Auth)"]
            MW_Auth["verifyToken & requireAdmin / requireOwner"]
            MW_Sentry["Sentry Error Handler"]
        end
    end

    Middlewares --> Routes

    subgraph ModularModules ["Tầng Nghiệp vụ Module (src/modules/*)"]
        subgraph ModuleStructure ["Cấu trúc chuẩn từng module"]
            Routes["*.routes.js<br/>(Khai báo endpoint, gán middleware)"]
            Controller["*.controller.js<br/>(Bắt request, parse Zod schema)"]
            Service["*.service.js<br/>(Nghiệp vụ, tính toán, transactional)"]
            Repo["*.repository.js / DB Query<br/>(SQL thuần qua pg pool)"]
            Routes --> Controller --> Service --> Repo
        end
    end

    subgraph CoreServices ["Dịch vụ lõi (src/services/* & src/config/*)"]
        MediaService["media.service.js<br/>(Quản lý upload Cloudinary)"]
        ActivityService["activity.service.js<br/>(Ghi log dòng thời gian CRM)"]
        ConfigEnv["src/config/env.js<br/>(Zod validate biến môi trường)"]
        DBPool["src/config/database.js<br/>(pg.Pool & directPool)"]
    end

    Service --> MediaService
    Service --> ActivityService
    Repo --> DBPool
    DBPool --> PostgresDB[("PostgreSQL Database")]
```

## 4. C4 Level 3: Thành Phần Web Frontend (apps/web Components)

Mô tả luồng dữ liệu, quản lý trạng thái và kiến trúc module của ứng dụng `apps/web`.

```mermaid
flowchart TD
    subgraph UIApp ["Tầng Ứng dụng & Điều hướng"]
        AppRouter["AppRouter & Layouts<br/>(Header, Footer, AdminGuard)"]
    end

    subgraph UIFeatures ["Tầng Tính năng (src/features/*)"]
        FeatStudio["features/studio<br/>(Canvas Konva, Template, Rules Engine)"]
        FeatLeads["features/leads & CRM<br/>(Form liên hệ, Activity Timeline, Báo giá)"]
        FeatServices["features/services<br/>(Bento Grid, ServiceDetailModal)"]
        FeatLookbook["features/lookbook<br/>(Lọc phong cách, ProjectAlbumModal)"]
        FeatTestimonials["features/testimonials<br/>(Đánh giá, Modal gửi phản hồi)"]
    end

    subgraph StateAndData ["Tầng Dữ liệu & Trạng thái Client"]
        TanStackQuery["TanStack Query (React Query)<br/>(Cache, Re-fetch, Stale Time)"]
        AuthContext["AuthContext & Store<br/>(Lưu token RAM, Silent Refresh)"]
        Mappers["Centralized Mappers<br/>(Chuyển đổi snake_case DTO <-> camelCase)"]
        HttpClient["src/lib/api.ts<br/>(Fetch wrapper, chèn Bearer Token, bắt lỗi 401)"]
    end

    subgraph SharedMonorepo ["packages/shared"]
        Contracts["Zod Schemas & DTO Types<br/>(Nguồn chân lý dữ liệu dùng chung)"]
    end

    AppRouter --> UIFeatures
    UIFeatures --> AuthContext
    UIFeatures --> TanStackQuery
    TanStackQuery --> Mappers
    Mappers --> HttpClient
    HttpClient -->|"Gửi request HTTPS"| BackendAPI["Express 5 API"]
    Mappers -.->|"Tuân thủ DTO Type"| Contracts
    HttpClient -.->|"Validate Zod Schema"| Contracts
```
